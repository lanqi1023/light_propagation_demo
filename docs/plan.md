# 角谱法空间光传播及退相干效应演示系统

## 一、系统架构与内存生命周期

零构建工具（纯 HTML/CSS/JS）。所有繁重计算（FFT、角谱传播、非理想叠加）运行在 Web Worker 中。主线程只负责 UI 交互和 Canvas 渲染。

### 1.1 文件结构

```
/
├── index.html          # 入口页面 (DOM + CSS)
├── style.css           # 样式布局
├── js/
│   ├── app.js          # 【主线程】UI 事件、状态机、Canvas 极速渲染（putImageData）
│   ├── colormap.js     # 【主线程】预计算 Inferno / HSV 色图 RGB 查找表
│   ├── worker.js       # 【子线程】消息路由、内存池管理、计算管线调度
│   ├── math/
│   │   └── fft.js      # 【子线程】纯 JS 2D FFT（位反转表 + 旋转因子表预计算）
│   └── physics/
│       ├── aperture.js # 【子线程】光阑生成（单缝/双缝/圆孔/矩形/自由/USAF1951）
│       ├── angspec.js  # 【子线程】带限角谱传播 (Band-Limited ASM + Zero-padding)
│       └── optics.js   # 【子线程】相干性叠加与偏轴控制
```

### 1.2 Worker 通信协议

#### 消息格式

```
主线程 → Worker:
{
  type: "compute",
  id: 42,                       // 自增请求 ID，主线程用此忽略过期响应
  params: {
    apertureType, apertureParams, w0,
    Nx, Ny, dx, dy,
    λ, dz,
    padding: true, bandLimited: true,
    tiltX, tiltY,               // 偏轴角
    temporalCoherence: false,    // 是否开启
    Δλ, M,                      // 时间相干参数
    spatialCoherence: false,     // 是否开启
    N_dir,                       // 空间相干参数（1D X方向）
  }
}

Worker → 主线程:
{
  type: "result",
  id: 42,
  intensity: Uint8Array,        // Nx × Ny, [0,255]
  phase:    Uint8Array,         // Nx × Ny, [0,255]
  crossX:   Float64Array,       // Ny
  crossY:   Float64Array,       // Nx
  info: { fresnelNum, Lx, Ly, computationTime, samplingOk }
}
```

#### 内存双缓冲机制（Ping-Pong Transfer）

当使用 `Transferable Object` 时，Worker 发送数据后自动失去所有权，无法再写入。为杜绝反复 `new` 触发 GC 停顿，采用双缓冲池：

```
初始化: 主线程预先创建两套 ArrayBuffer（Buffer A, Buffer B）

帧 N:
  1. 主线程将 Buffer A 的所有权转移给 Worker（连同计算参数）
  2. Worker 将结果写入 Buffer A，把控制权转回主线程
  3. 主线程收到 Buffer A，用 putImageData 渲染
  4. 同时发起帧 N+1 请求，此时使用 Buffer B
  5. 渲染完毕后 Buffer A 空闲，等待复用

效果: 零 Allocation，彻底消除 GC
```

## 二、FFT 实现规范 (`math/fft.js`)

### 2.1 数据布局

`Float64Array`，复数按**交叉存储** `[Re0, Im0, Re1, Im1, ...]`，二维按行主序展平 `idx = (i * Ny + j) * 2`，原地计算。

### 2.2 1D FFT（基-2 Cooley-Tukey）

```
fft1d(arr, n, inverse)
```

- n 必须是 2 的幂
- **预计算表（关键优化）**：在 Nx/Ny 变化时，提前计算位反转索引表（`bitrev[n]`）和旋转因子表（`W[n/2]` 的 `cos/sin` 值），避免每次 FFT 重新计算三角函数
- 蝶形迭代（非递归），位反转重排后原地循环
- 符号约定（匹配角谱法）：
  - 正变换：`F(k) = Σ f(n) · exp(-i·2π·kn/N)`
  - 逆变换：`f(n) = (1/N) · Σ F(k) · exp(+i·2π·kn/N)`

### 2.3 2D FFT

```
fft2d(arr, nx, ny, inverse)
```

每行 1D FFT → 转置 → 每列 1D FFT → 转置回来。O(N² log N)。

### 2.4 fftshift / ifftshift

```
fftshift(arr, nx, ny)     # 零频 → 中心（显示用）
ifftshift(arr, nx, ny)    # 零频 → 角落（FFT 用）
```

### 2.5 验证

- 脉冲测试：`[1,0, 0,0, ...]` → 正变换后全为常数
- 闭环测试：随机数组 forward + inverse 恢复原值（误差 < 1e-12）
- 高斯函数 FFT 仍是高斯，验证半高宽

## 三、角谱法传播 (`physics/angspec.js`)

### 3.1 算法流程（Matsushima 2009 严格带限 + 零填充）

```
propagate(U0, Nx, Ny, dx, dy, λ, dz, {padding=true, bandLimited=true})
```

FFT 假设周期性边界条件，光束传播到窗口边缘会从另一侧卷绕（wrap-around）。解决：**2× 零填充** + **严格频带限制**。

```
步骤:

1. 零填充（若 padding=true）:
   - 内部创建 2Nx × 2Ny 数组，U0 置于中心，四周补零
   - N_i = 2Nx, M_i = 2Ny，dx, dy 不变
   - 物理窗口 Lx = Nx·dx, Ly = Ny·dy

2. 频率坐标:
   fx[m] = m / (N_i · dx),  m = -N_i/2, ..., N_i/2-1
   fy[n] = n / (M_i · dy),  n = -M_i/2, ..., M_i/2-1

3. ifftshift → fft2d → 得到 A0(fx,fy)

4. 构造传递函数 H(fx,fy)（Matsushima 严格带限）:
   k  = 2π / λ
   kz = √(k² - (2π·fx)² - (2π·fy)²)

   截止频率（Matsushima 2009）:
     fx_limit = 1/(2·dx) · 1/√(1 + (λ·dz / Lx)²)
     fy_limit = 1/(2·dy) · 1/√(1 + (λ·dz / Ly)²)

   H(fx,fy) = exp(i · dz · kz)
     当 |fx| > fx_limit 或 |fy| > fy_limit → H = 0（混叠滤波）
     当 (2π·fx)² + (2π·fy)² > k²       → H = 0（倏逝波截断）

   ⚠ 频率坐标陷阱：截止频率 mask 必须基于 fftshift 后的坐标（零频在中心），
     与 FFT 内部的内存布局保持一致。

5. Az = A0 · H（逐元素复数乘法）

6. fftshift → ifft2d → ifftshift

7. 从 2Nx × 2Ny 中裁剪中心 Nx × Ny 区域

8. 输出 Float64Array（Nx × Ny × 2，交叉存储）
```

### 3.2 采样监控（UI 仪表盘）

每次计算前验证，UI 显示绿色 ✓ / 红色 ⚠ 指示灯：

| 条件 | 公式 | 说明 |
|------|------|------|
| 空间 Nyquist | `dx ≤ λ/2` | 大角度衍射基本要求 |
| 菲涅尔数 | `F = (Lx/2)² / (λ·dz)` | F≫1 近场, F≪1 远场 |
| 传播距离上限 | `dz ≤ N·dx²/λ` | 标准 ASM，带限后可放宽 |
| 物理窗口 | `Lx = Nx·dx` | 模拟的真实物理范围 |

## 四、预设光阑 (`physics/aperture.js`)

### 4.1 接口

```
generateAperture(type, Nx, Ny, dx, dy, params) → Float64Array
```

返回交叉存储的复振幅（透射区幅度=1，阻挡区=0；虚部=0）。

### 4.2 种类

| 光阑 | 参数 | 说明 |
|------|------|------|
| 单缝 | 缝宽 a | 经典衍射物体 |
| 双缝 | 缝宽 a, 缝间距 d | 杨氏双缝干涉 |
| 圆孔 | 半径 R | Airy 斑 |
| 矩形孔 | 宽 a, 高 b | 二维矩形衍射 |
| 自由传播 | — | 全 1 |
| **USAF1951 分辨率板** | — | 三线图案，光学分辨率标准测试目标 |

### 4.3 增强

所有光阑可选叠加**高斯幅度包络** `exp(-(x²+y²)/w₀²)` 模拟激光束腰，默认 `w₀=∞`（平面波）。

## 五、非理想因素 (`physics/optics.js`)

### 5.1 偏轴照明（零额外开销）

```
U_in(x,y) = U0(x,y) · exp(i · k · (sinθx·x + sinθy·y))
```

- 单次传播，计算量与无偏轴相同
- θx, θy ∈ [-10°, 10°]
- 近场：图案平移；远场：衍射斑形变

### 5.2 有限时间相干性（宽光谱叠加）

```
I_total = Σ w(λ_m) · |U(λ_m)|²    M ∈ {1, 3, 5, 7}
```

- 高斯光谱，FWHM = Δλ
- 每个 λ 独立传播，强度加权求和
- M 默认 **5**（不要更大，足以看到条纹退化）

### 5.3 有限空间相干性（一维扩展光源）

```
I_total = Σ w(θ_k) · |U(θ_k)|²    K ∈ {1, 3, 5, 7}
```

- **仅沿 X 方向**倾斜（一维），不做二维网格
- 角度高斯分布，宽度对应光源尺寸
- 物理意义：狭缝光源的 Van Cittert-Zernike 退相干

### 5.4 组合模式

- 时间 + 空间同时开启：总计算量 = M × K
- 算力保护锁：M×K ≥ 9 时网格自动降级（128×128）；M×K ≥ 25 时降级至 64×64
- UI 进度条显示 `(当前/总数)`

## 六、前端渲染 (`colormap.js` + `app.js`)

### 6.1 查表法极速渲染

主线程**绝不执行复数运算**，只接收 Worker 传来的 Uint8Array 数据。

```
1. 强度图 (Inferno): 预计算 256×3 RGB 表 → Uint8ClampedArray → putImageData
2. 相位图 (HSV 色环 + Alpha 遮罩):
   - φ ∈ [-π, π] → Hue ∈ [0°, 360°]
   - Alpha 遮罩：当 I(x,y) < 0.05 × Imax 时 Alpha=0（透明黑色），
     避免暗场区域相位噪声干扰视觉
   → Uint8ClampedArray → putImageData
```

### 6.2 输入光阑预览

- 在主线程中独立渲染输入场幅度图（不需 Worker）
- 大小与输出图对齐，方便对比

## 十、技术风险预警与对策

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| JS 浮点性能天花板：512×512 + 25 次循环 ≥ 2s | 高 | 中 | 实时(≤256) vs 高精(512) 模式；非理想时自动降级至 64/128 |
| 频率坐标陷阱：带限 mask 坐标系与 FFT 内部不匹配 | 高 | 高 | 代码中显式注释频率坐标布局；统一使用 fftshift 后坐标做 mask |
| Transferable Object 所有权转移后 Worker 内释放 | 中 | 中 | 双缓冲 Ping-Pong，零 allocation |
| 空间相干二维角度网格 (K²) 不可承受 | 中 | 高 | **强制一维**，仅在 X 方向 |
| 传函采样 aliasing 在远场导致全错 | 中 | 高 | Matsushima 带限滤波 + UI 红色警告 |
| 色环相位图暗场区域噪点误导 | 低 | 中 | Alpha 遮罩（I < 5% Imax 透明） |
